# Simple Interest Calculator

## Description

This project calculates simple interest given the principal amount, annual rate of interest, and time period in years.

## Features

- Calculates Simple Interest
- Easy to use Bash script
- Beginner-friendly

## Formula Used

Simple Interest = (Principal × Rate × Time) / 100

## How to Run

1. Clone the repository.
2. Open a terminal.
3. Run:

```bash
bash simple-interest.sh
```

4. Enter the Principal, Rate, and Time when prompted.

## Example

Input:
- Principal: 10000
- Rate: 5
- Time: 2

Output:
```
Simple Interest is: 1000
```
